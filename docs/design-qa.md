## 页面操作证据

通过 Codex in-app browser 操作真实页面，未使用页面脚本注入点击或伪造 UI 结果：

1. 上传真实合成 PDF 共 120 页 → 按 30 人均分 → 合并为 29 份 → 撤销恢复 30 份。
2. 勾选五份 → 打开对话记录中的安排入口 → 保存自由检查任务 → 确认仅五份、状态为草稿。
3. 在原页拖动框选 → 出现对应页码标签 → 提问 → 上游 Pi 工具循环实际读取裁剪 → 返回明确标注离线演示的回复与工具记录。
4. Pi `ask_teacher` 产生问题 → 页面打开对应 MS 页 → 暂停 → 附圈选回复 → 后续请求保持等待 → 继续 → 问题结束、待确认数量减少。
5. 打开答卷待定评分 → 选择允许分值并写理由 → 保存 → 原评分保持待定、老师复核为 1 分。
6. 390px 下四行输入增高到 96px 文本区、193px 含引用输入框；清空文字并移除引用后恢复 24px 文本区、84px 输入框。
7. 桌面、平板和手机无文档根节点横向溢出。最后两个新页面的 error / warn 控制台查询均为空数组。没有白屏、框架错误覆盖或缺失静态资源。

浏览器操作使用 `getByRole`、文件选择器、原生 `drag`、截图和只读 DOM 尺寸检查。自由曲线路径的边界和缩放以纯坐标测试覆盖；浏览器自动拖动验证的是矩形选区，未声称完成真实手写笔或多点触控验收。
