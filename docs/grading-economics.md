# 约千页的批改预算，算的是哪笔钱？

[返回首页](../README.md) · [工作台操作](WORKSPACE.md)

**假设：33 位学生，每份 30 页，同一套题，复用老师确认的标准。** 项目方提供的学生批改模型费预算如下，不是 33 份不同答卷的实付账单、固定报价或费用上限。

| 执行模型 | 全班 990 页 | 折合每份 30 页 |
| :--- | ---: | ---: |
| Luna | 不到 $0.50 | 不到 1.52 美分 |
| Terra | 约 $3.00 | 约 9.1 美分 |

模型按用量而非页数计费。首次整理标准、查图、自查、反馈、主 Agent 汇总和失败重试都可能增加费用；教师复核与本地运行成本另算。

### 并行省的是等待，不是复核

**单卷实测（2026-11-17）：** 对同一份 28 页答卷复用已确认标准，包含图像准备、初批、自查、个人反馈与汇总，Luna 轮次耗时 **138 秒、$0.0400**，Terra 轮次耗时 **118 秒、$0.2284**。这是比预算示例更长的流程，两次都只处理一份答卷；它们不是千页测速，也不能证明普遍的质量或速度差异。

手工逐份批改，后面的答卷要排队。GradeOS 把采用的同版标准交给多个独立任务，可以同时处理不同学生的答卷；不把全班笔迹混在一个对话里。实际耗时取决于批次安排、并发上限、模型服务限流与重试。整班速度应从提交第一份计到最后一份结果可用，并另记待定数、失败数和教师复核时间，不能拿单卷时间直接外推。

### 和人工、其他工具公平比较

如果教师每份纯手工批改需 15 分钟（示例假设），33 份是 **8 小时 15 分钟**。这不是 GradeOS 已节省的工时：要减去老师准备标准、审阅和纠错的实际时间。比较其他工具时，也应在同一组答卷、同样的批注和复核要求下，把订阅或用量费、整理材料和导出的工时一起算入。没有同条件计时和账单，就不声称快几倍或便宜几倍。
