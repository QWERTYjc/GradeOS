# 批注阅读与导出迁移

将旧仓库 `experiments/pi-grading` 中的批注展示能力适配到独立 GradeOS，沿用新仓库的结果入口、按题审阅、复核草稿、数学报告阅读器和可编辑评分实施文档。

## 阅读与打印

- 原卷附近的空白处显示细勾叉和简短理由；标记与理由合并，最多两行。距离较远时使用牵引线，空间不足时延续到页后，避免盖住笔迹或其他批注。
- 笔迹区域平时不着色，悬停理由或选中评分点时才高亮；点击打开完整理由、评分依据和原始记录。
- 原卷支持连续滚动和逐页翻阅，MS 可独立并排滚动。窗口宽度变化时保留阅读位置。
- 现有结果栏增加“评分明细”，显示逐题得分与完整评分点记录，可下载 Markdown。查看明细时收起重复的审阅侧栏。
- PDF 含评分总览、原页上的勾叉与简短理由，以及默认关闭的完整批注；不打印整片高亮框。

## 保持的边界

- 模型、提示词、评分协议、评分实施确认、任务状态、预算、OCR 生产逻辑和按需定位机制不变。没有迁入旧实验的模型路由或成本配置。
- 展示层消费现有已保存的来源绑定区域；本地 OCR 区域编号与元数据可直接显示，既有结果的区域格式继续兼容。此次迁移不意味着所有新批次都会改用 OCR 或 Luna。
- 新的空白检测、排布和 PDF 绘制在浏览器或本地脚本中完成，不调用模型。Python 使用独立仓库已有环境，未新增运行依赖。
- 复核结果必须匹配任务、记录和原始哈希；未知分数、定性反馈和未完成批次分别显示，不改写原评分。
- 上传、答卷划分、现有个人及汇总报告、公式目录和教师审阅仍走原有入口。
