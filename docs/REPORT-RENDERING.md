# 报告阅读与公式排版

报告的评分记录、Markdown 和导出内容仍是原始来源；渲染不回写模型产物，不增加模型
调用，也不改变复核状态。浏览器直接使用 ESM，无前端构建步骤。

- `document-reader.mjs` 从二、三级标题生成分章目录与题号搜索；保留全文阅读和独立的
  窗口阅读位置。旧版单张评分表按已有题号分组展示，不推断或删减评分点。
- `ui.mjs` 在 Markdown 表格与强调语法之前保护代码和公式。块公式中的换行、矩阵
  列分隔符和脚标不会变成段落、表格列或强调；代码示例、金额、链接与版本号保持原样。
- `report-math.mjs` 使用固定版本 KaTeX 输出原生 MathML。仅一个本地依赖模块，
  不加载外部字体、CDN 或模型；服务仅开放该模块的确切路径，不开放整个依赖目录。
  使用支持 MathML 的现代浏览器；可在 Chrome 中检查 `mfrac`、`msubsup`、`mtable`
  的实际排版。渲染失败保留原文，拒绝可执行命令并限制宏展开及自定义尺寸。
- 公式元素保留原文字串与字符偏移。选中公式时引用完整的原文；混合选区必须能精确
  映射回源文件，否则沿用编辑模式选取，不推测证据位置。折叠或隐藏章节的注释不会
  错挂到其他章节。复制公式与 Markdown 下载都保留源表达式。

`math-text-parser.mjs` 从旧 GradeOS 的
`frontend/src/components/common/mathTextParser.ts` 移植，去掉 TypeScript 类型并补齐
裸公式的多位数字上下标处理，保留源码哈希、GPL-3.0 归属和原有的解析回归测试。
它兼容明确的 LaTeX 分隔符、
裸 LaTeX，以及可明确识别的 Unicode/OCR 形式；不猜测歧义表达式或修正数学答案。
KaTeX 的 MIT 许可保留在 `THIRD_PARTY_LICENSES/KaTeX-MIT.txt`。

`npm run check` 包含公式语义结构、源文偏移、安全回退、完整依据、静态资源和现有
批改契约测试，不请求模型。浏览器验收另在新的 `runs/` 目录保存截图和下载校验，
至少覆盖桌面/手机、分章跳转、公式选取与注释，以及原报告下载前后的内容一致性。
